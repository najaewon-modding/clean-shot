# CleanShot

**채팅은 깔끔하게 숨기고, 촬영 위치 정보는 남기는 Minecraft 스크린샷 유틸리티 모드입니다.**

CleanShot은 Minecraft의 기본 스크린샷 기능을 확장하는 **클라이언트 전용** NeoForge 모드입니다. 평소 플레이 화면에서는 채팅 HUD를 제외한 깔끔한 스크린샷을 촬영하고, 필요하면 좌표와 촬영 정보를 함께 기록할 수 있습니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |
| Java | `25` |
| 설치 위치 | 클라이언트 전용 |

## 주요 기능

### 채팅 HUD 숨기기

기본 설정에서는 일반 플레이 중 화면에 표시되는 채팅 HUD가 스크린샷에 포함되지 않습니다.

- 일반 채팅 메시지
- 시스템 메시지
- 명령어 실행 결과
- 플레이어 접속/퇴장 메시지
- 스크린샷 저장 메시지

조준점, 단축바, 체력, 방어력 등 다른 HUD 요소는 그대로 유지됩니다.

`T` 또는 `/` 키로 채팅 화면을 직접 열어 둔 상태에서는 채팅 기록과 입력창도 함께 촬영됩니다. 따라서 평소에는 채팅 없는 스크린샷을 찍고, 채팅 내용을 남기고 싶을 때만 의도적으로 포함할 수 있습니다.

### 좌표가 포함된 파일 이름

스크린샷 파일 이름에 현재 블록 좌표를 포함할 수 있습니다.

```text
2026-08-25_02.15.32_[123,64,-456].png
```

이 기능은 설정에서 끌 수 있습니다.

### PNG 촬영 정보 기록

PNG 파일 내부에 다음 촬영 정보를 기록할 수 있습니다.

- 정확한 X, Y, Z 좌표
- 차원
- Yaw
- Pitch

파일 이름을 바꾸더라도 PNG 내부의 촬영 정보는 유지됩니다.

### CSV 촬영 로그

`screenshots/cleanshot.csv` 파일에 다음 정보를 누적 기록할 수 있습니다.

- 스크린샷 파일 경로
- 정확한 X, Y, Z 좌표
- 차원
- Yaw
- Pitch

CSV 로그 기능은 설정에서 끌 수 있습니다.

### 날짜별 자동 정리

스크린샷을 촬영 날짜별 하위 폴더에 자동으로 정리할 수 있습니다.

```text
screenshots/
├── cleanshot.csv
├── 2026-08-25/
│   ├── 2026-08-25_02.15.32_[123,64,-456].png
│   └── 2026-08-25_02.18.41_[130,65,-440].png
└── 2026-08-26/
    └── 2026-08-26_00.03.14_[850,72,132].png
```

## 설정

Minecraft의 모드 설정 화면에서 기능별 동작을 변경할 수 있습니다.

```text
Mods
→ CleanShot
→ Config
```

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 파일 이름에 좌표 포함 | ON | 파일 이름에 X, Y, Z 좌표를 추가합니다. |
| CSV 로그 생성 | ON | `cleanshot.csv`에 촬영 정보를 기록합니다. |
| 날짜별로 스크린샷 정리 | ON | 날짜별 하위 폴더에 스크린샷을 저장합니다. |
| 스크린샷에서 채팅 숨기기 | ON | 일반 플레이 중 채팅 HUD를 스크린샷에서 제외합니다. |

## 사용 방법

기본 Minecraft와 동일하게 `F2` 키로 스크린샷을 촬영합니다. 별도의 촬영 키는 추가되지 않습니다.

## 설치

1. Minecraft `26.1.2`용 NeoForge `26.1.2.97`을 설치합니다.
2. CleanShot JAR 파일을 클라이언트의 `mods` 폴더에 넣습니다.
3. Minecraft를 실행합니다.

서버에는 설치할 필요가 없습니다.
