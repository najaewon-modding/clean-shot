# CleanShot

**채팅은 깔끔하게 숨기고, 촬영 위치 정보는 남기는 Minecraft 스크린샷 유틸리티 모드입니다.**

CleanShot은 Minecraft의 기본 스크린샷 기능을 확장하는 **클라이언트 전용** NeoForge 모드입니다. 일반 플레이 중 화면에 떠 있는 채팅 HUD를 스크린샷에서 자동으로 제외하고, 촬영 당시의 위치와 시점 정보를 파일 이름, PNG 메타데이터, CSV 로그에 기록할 수 있습니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |
| Java | `25` |
| 실행 환경 | 클라이언트 전용 |

## 주요 기능

### 채팅 HUD가 없는 스크린샷

기본 설정에서는 일반 플레이 중 화면 왼쪽 아래에 표시되는 채팅 HUD가 스크린샷에 포함되지 않습니다.

다음과 같은 메시지가 화면에 떠 있어도 스크린샷에서는 제거됩니다.

- 일반 채팅 메시지
- 시스템 메시지
- 명령어 실행 결과
- 플레이어 접속/퇴장 메시지
- 스크린샷 저장 메시지

월드, 조준점, 단축바, 체력, 방어력 등 다른 HUD 요소는 그대로 유지됩니다. 채팅 메시지 자체를 삭제하는 기능은 아니며, 스크린샷을 캡처하는 순간 채팅 HUD의 렌더링만 제외합니다.

### 채팅 화면을 직접 연 경우에는 채팅 포함

`T` 또는 `/` 키 등으로 채팅 입력 화면을 직접 열어 둔 상태에서 촬영하면 채팅 기록과 입력창을 모두 포함합니다.

```text
일반 플레이 + F2
→ 채팅 HUD 제외

T 또는 / 로 채팅 화면 열기 + F2
→ 채팅 기록 포함
→ 채팅 입력창 포함
```

따라서 평소에는 깔끔한 스크린샷을 촬영하면서도, 채팅 내용을 의도적으로 기록하고 싶을 때는 기존 Minecraft와 같은 방식으로 촬영할 수 있습니다.

### 좌표가 포함된 파일 이름

스크린샷 파일 이름에 플레이어의 현재 블록 좌표를 포함할 수 있습니다.

```text
2026-08-25_02.15.32_[123,64,-456].png
```

형식은 다음과 같습니다.

```text
YYYY-MM-DD_HH.mm.ss_[X,Y,Z].png
```

이 기능은 설정에서 끌 수 있습니다.

### PNG 메타데이터

PNG 파일 내부에 촬영 당시의 위치와 카메라 정보를 기록합니다.

```text
CleanShot.Position = 123.472839,64.000000,-456.182731
CleanShot.Dimension = minecraft:overworld
CleanShot.Yaw = 143.72
CleanShot.Pitch = -18.43
```

기록되는 정보:

- 정확한 X, Y, Z 좌표
- Dimension
- Yaw
- Pitch

파일 이름을 변경해도 PNG 내부의 촬영 정보는 유지됩니다. Windows 파일 탐색기의 `속성 → 자세히` 화면에서는 사용자 정의 PNG 메타데이터가 표시되지 않을 수 있습니다.

### CSV 촬영 로그

스크린샷을 촬영할 때 `screenshots/cleanshot.csv`에 촬영 정보를 누적 기록할 수 있습니다.

```csv
File,X,Y,Z,Dimension,Yaw,Pitch
"2026-08-25/2026-08-25_02.15.32_[123,64,-456].png",123.472839,64.000000,-456.182731,"minecraft:overworld",143.72,-18.43
```

CSV에는 다음 정보가 저장됩니다.

- 스크린샷 파일 경로
- 정확한 X, Y, Z 좌표
- Dimension
- Yaw
- Pitch

CSV 로그 기능은 설정에서 끌 수 있습니다.

### 날짜별 스크린샷 정리

스크린샷을 촬영 날짜별 하위 폴더에 자동으로 정리할 수 있습니다.

```text
screenshots/
├── cleanshot.csv
├── 2026-08-25/
│   ├── 2026-08-25_02.15.32_[123,64,-456].png
│   └── 2026-08-25_02.18.41_[130,65,-440].png
└── 2026-08-26/
    └── 2026-08-26_00.03.14_[850,72,132].png
```

CSV 파일은 날짜별 폴더로 나뉘지 않고 `screenshots` 루트에 하나만 유지됩니다.

## 설정

Minecraft의 모드 설정 화면에서 기능별 동작을 변경할 수 있습니다.

```text
Mods
→ CleanShot
→ Config
```

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 파일 이름에 좌표 포함 | ON | 파일 이름에 X, Y, Z 좌표를 추가합니다. |
| CSV 로그 생성 | ON | `cleanshot.csv`에 촬영 정보를 기록합니다. |
| 날짜별로 스크린샷 정리 | ON | 날짜별 하위 폴더에 스크린샷을 저장합니다. |
| 스크린샷에서 채팅 숨기기 | ON | 일반 플레이 중 채팅 HUD를 스크린샷에서 제외합니다. |

채팅 숨기기 설정을 꺼 두면 일반 Minecraft와 동일하게 화면에 떠 있는 채팅 HUD도 촬영됩니다. 단, 설정과 관계없이 채팅 화면을 직접 열어 둔 경우에는 채팅 기록과 입력창이 촬영됩니다.

## 설치

1. Minecraft `26.1.2`용 NeoForge `26.1.2.97`을 설치합니다.
2. CleanShot JAR 파일을 클라이언트의 `mods` 폴더에 넣습니다.
3. Minecraft를 실행합니다.

서버에는 CleanShot을 설치할 필요가 없습니다. 일반 멀티플레이 서버에서도 클라이언트에만 설치하여 사용할 수 있습니다.

## 사용 방법

기본 Minecraft와 동일하게 스크린샷 키를 사용합니다.

```text
F2
```

CleanShot은 별도의 촬영 키를 추가하지 않고 Minecraft의 기존 스크린샷 흐름을 확장합니다.

## 동작 범위

CleanShot의 기능은 모두 클라이언트에서 처리됩니다.

- 스크린샷 캡처
- 채팅 HUD 렌더링 제어
- 플레이어 위치 및 시점 정보 확인
- 파일 이름 변경
- PNG 메타데이터 기록
- CSV 로그 기록
- 날짜별 폴더 정리
