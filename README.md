# CleanShot

**채팅은 깔끔하게 숨기고, 촬영 위치 정보는 남기는 Minecraft 스크린샷 유틸리티 모드입니다.**

CleanShot은 Minecraft의 기본 스크린샷 기능을 확장하는 **클라이언트 전용(Client-side only)** NeoForge 모드입니다.

스크린샷을 촬영할 때 평소 화면에 떠 있는 채팅 HUD를 자동으로 제외하고, 촬영 당시의 위치와 시점 정보를 파일명, PNG 메타데이터, CSV 로그에 기록할 수 있습니다.

## 지원 버전

| 항목        | 버전          |
| --------- | ----------- |
| CleanShot | `1.0.0`     |
| Minecraft | `26.1.2`    |
| NeoForge  | `26.1.2.97` |
| Java      | `25`        |

## 주요 기능

### 채팅 HUD가 없는 깔끔한 스크린샷

기본 설정에서는 일반 플레이 중 화면 왼쪽 아래에 표시되는 채팅 HUD가 스크린샷에 포함되지 않습니다.

다음과 같은 메시지가 화면에 떠 있어도 스크린샷에서는 제거됩니다.

* 일반 채팅 메시지
* 시스템 메시지
* 명령어 실행 결과
* 플레이어 접속/퇴장 메시지
* 스크린샷 저장 메시지

다른 HUD 요소는 그대로 유지됩니다.

```text
일반 플레이 + F2

World       O
Crosshair   O
Hotbar      O
Health      O
Armor       O
Chat HUD    X
```

채팅 메시지 자체가 삭제되는 것은 아닙니다. 평소 화면에서 렌더링되는 채팅 HUD만 스크린샷에서 제외합니다.

### 채팅 화면을 직접 연 경우에는 채팅 포함

`T` 또는 `/` 키 등을 사용해 채팅 입력 화면을 직접 열어놓은 상태에서는 채팅 기록과 입력창을 모두 포함하여 촬영합니다.

```text
일반 플레이 + F2
    → 채팅 HUD 제외

T 또는 / 로 채팅 화면 열기 + F2
    → 채팅 기록 포함
    → 채팅 입력창 포함
```

따라서 평소에는 깔끔한 스크린샷을 촬영하면서도, 채팅 내용을 의도적으로 기록하고 싶을 때는 기존 Minecraft와 동일하게 촬영할 수 있습니다.

### 좌표가 포함된 파일 이름

스크린샷 파일 이름에 플레이어의 현재 블록 좌표를 포함할 수 있습니다.

예:

```text
2026-08-25_02.15.32_[123,64,-456].png
```

형식:

```text
YYYY-MM-DD_HH.mm.ss_[X,Y,Z].png
```

이 기능은 설정에서 끌 수 있습니다.

### PNG 메타데이터

스크린샷 PNG 내부에 촬영 당시의 위치 및 카메라 정보를 기록합니다.

저장되는 메타데이터:

```text
CleanShot.Position = 123.472839,64.000000,-456.182731
CleanShot.Dimension = minecraft:overworld
CleanShot.Yaw = 143.72
CleanShot.Pitch = -18.43
```

포함되는 정보:

* 정확한 X, Y, Z 좌표
* Dimension
* Yaw
* Pitch

파일 이름을 변경하더라도 PNG 파일 내부에는 촬영 정보가 유지됩니다.

> Windows 파일 탐색기의 `속성 → 자세히` 화면에서는 CleanShot의 사용자 정의 PNG 메타데이터가 표시되지 않을 수 있습니다.

### CSV 로그

스크린샷을 촬영할 때 `screenshots` 폴더에 `cleanshot.csv`를 생성하여 촬영 정보를 누적 기록할 수 있습니다.

예:

```csv
File,X,Y,Z,Dimension,Yaw,Pitch
"2026-08-25/2026-08-25_02.15.32_[123,64,-456].png",123.472839,64.000000,-456.182731,"minecraft:overworld",143.72,-18.43
```

CSV에는 다음 정보가 기록됩니다.

* 스크린샷 파일 경로
* 정확한 X, Y, Z 좌표
* Dimension
* Yaw
* Pitch

`cleanshot.csv`는 일반 텍스트 편집기나 Excel 등의 프로그램으로 바로 확인할 수 있습니다.

CSV 로그 생성 기능은 설정에서 끌 수 있습니다.

### 날짜별 스크린샷 정리

스크린샷을 촬영 날짜별 폴더에 자동으로 정리할 수 있습니다.

예:

```text
screenshots/
├── cleanshot.csv
├── 2026-08-25/
│   ├── 2026-08-25_02.15.32_[123,64,-456].png
│   └── 2026-08-25_02.18.41_[130,65,-440].png
└── 2026-08-26/
    └── 2026-08-26_00.03.14_[850,72,132].png
```

CSV 파일은 날짜별 폴더 안에 나뉘지 않고 `screenshots` 루트에 하나만 유지됩니다.

날짜별 정리 기능 역시 설정에서 끌 수 있습니다.

## 설정

Minecraft의 모드 설정 화면에서 CleanShot의 기능을 변경할 수 있습니다.

```text
Mods
→ CleanShot
→ Config
```

현재 제공되는 설정:

| 설정            | 기본값 | 설명                                  |
| ------------- | --- | ----------------------------------- |
| 파일 이름에 좌표 포함  | ON  | 스크린샷 파일 이름에 X, Y, Z 좌표를 추가합니다.      |
| CSV 로그 생성     | ON  | `cleanshot.csv`에 촬영 정보를 기록합니다.      |
| 날짜별로 스크린샷 정리  | ON  | 날짜별 하위 폴더에 스크린샷을 저장합니다.             |
| 스크린샷에서 채팅 숨기기 | ON  | 일반 플레이 중 표시되는 채팅 HUD를 스크린샷에서 제외합니다. |

채팅 숨기기 설정을 꺼두면 일반 Minecraft와 동일하게 화면에 떠 있는 채팅 HUD도 스크린샷에 포함됩니다.

단, 설정과 관계없이 `T` 또는 `/` 등을 통해 채팅 화면을 직접 열어놓은 경우에는 채팅 기록과 입력창이 촬영됩니다.

## 클라이언트 전용

CleanShot은 **클라이언트 전용 모드**입니다.

서버에는 CleanShot을 설치할 필요가 없습니다.

```text
Client
    CleanShot 설치 O

Server
    CleanShot 설치 X
```

일반 멀티플레이 서버에서도 클라이언트에만 CleanShot을 설치하여 사용할 수 있습니다.

CleanShot이 사용하는 기능은 모두 클라이언트에서 처리됩니다.

* 스크린샷 캡처
* 채팅 HUD 렌더링 제어
* 플레이어 위치 및 시점 정보 확인
* 파일 이름 변경
* PNG 메타데이터 기록
* CSV 로그 기록
* 날짜별 폴더 정리

## 설치

1. Minecraft `26.1.2`용 NeoForge `26.1.2.97`을 설치합니다.
2. CleanShot `1.0.0` JAR 파일을 다운로드합니다.
3. JAR 파일을 Minecraft의 `mods` 폴더에 넣습니다.
4. Minecraft를 실행합니다.

서버에는 별도의 설치가 필요하지 않습니다.

## 스크린샷 촬영

기본 Minecraft와 동일하게 스크린샷 키를 사용합니다.

기본 키:

```text
F2
```

CleanShot은 기존 Minecraft의 스크린샷 기능을 기반으로 동작하므로 별도의 촬영 키를 추가하지 않습니다.

기본 설정을 모두 활성화한 상태에서 스크린샷을 촬영하면:

```text

├── cleanshot.csv
└── 2026-08-25/
    └── 2026-08-25_02.15.32_[123,64,-456].png
```

PNG 내부:

```text
CleanShot.Position = 123.472839,64.000000,-456.182731
CleanShot.Dimension = minecraft:overworld
CleanShot.Yaw = 143.72
CleanShot.Pitch = -18.43
```

CSV:

```csv
File,X,Y,Z,Dimension,Yaw,Pitch
"2026-08-25/2026-08-25_02.15.32_[123,64,-456].png",123.472839,64.000000,-456.182731,"minecraft:overworld",143.72,-18.43
```
