# CleanTrace

**채팅은 숨기고, 촬영 위치 정보는 남기는 Minecraft 스크린샷 유틸리티 모드입니다.**

CleanTrace는 Minecraft의 기본 스크린샷 기능을 확장하는 클라이언트 전용 모드입니다.

스크린샷을 촬영할 때 화면에 표시된 일반 채팅 메시지를 자동으로 제외하고, 촬영 당시의 좌표와 시점 정보를 파일명 및 PNG 메타데이터에 기록합니다.

## 개발 환경

| 항목         | 버전          |
| ---------- | ----------- |
| CleanTrace | `0.1.0`     |
| Minecraft  | `26.1.2`    |
| NeoForge   | `26.1.2.97` |

## 주요 기능

### 좌표가 포함된 스크린샷 파일명

스크린샷을 촬영하면 파일명에 플레이어의 현재 블록 좌표를 자동으로 기록합니다.

예:

```text
2026-08-25_00.05.31_[123,64,-456].png
```

파일명 형식은 다음과 같습니다.

```text
YYYY-MM-DD_HH.mm.ss_[X,Y,Z].png
```

파일명에는 스크린샷을 쉽게 검색하고 구분할 수 있도록 정수 블록 좌표를 사용합니다.

### PNG 메타데이터 기록

스크린샷 파일 내부에도 촬영 당시의 정보를 메타데이터로 저장합니다.

기록 대상은 다음과 같습니다.

* 정확한 X 좌표
* 정확한 Y 좌표
* 정확한 Z 좌표
* 차원(Dimension)
* Yaw
* Pitch

따라서 스크린샷 파일의 이름을 변경하더라도 PNG 내부에 저장된 정보를 통해 원래 촬영 위치와 바라보던 방향을 확인할 수 있습니다.

예를 들어 다음과 같은 정보가 저장될 수 있습니다.

```text
X = 123.472839
Y = 64.000000
Z = -456.182731
Dimension = minecraft:overworld
Yaw = 143.72
Pitch = -18.43
```

### 채팅이 없는 깔끔한 스크린샷

일반적인 게임 플레이 중 스크린샷을 촬영하면 현재 화면에 표시되고 있는 채팅 메시지를 스크린샷에서 자동으로 제외합니다.

다른 HUD 요소는 그대로 유지합니다.

```text
일반 게임 화면 + F2
    → 채팅 메시지 제외
    → 다른 HUD는 유지
```

단, `T` 키 등을 눌러 채팅 화면을 직접 열어놓은 상태에서는 채팅을 포함하여 촬영합니다.

```text
채팅 화면이 닫혀 있음 + F2
    → 채팅 숨김

채팅 화면이 열려 있음 + F2
    → 채팅 포함
```

즉, 플레이 도중 우연히 화면에 떠 있는 채팅 메시지는 제거하지만, 사용자가 의도적으로 채팅 화면을 열어 촬영한 경우에는 해당 내용을 보존합니다.

## 클라이언트 전용

CleanTrace는 **클라이언트 전용(Client-side only)** 모드입니다.

서버에 CleanTrace를 설치할 필요가 없습니다.

다음 정보와 기능은 모두 Minecraft 클라이언트에서 처리됩니다.

* 플레이어 위치
* 현재 차원
* Yaw / Pitch
* HUD 및 채팅 렌더링
* 스크린샷 캡처
* 파일명 생성
* PNG 메타데이터 기록

따라서 일반 서버에서도 클라이언트에 CleanTrace만 설치하여 사용할 수 있도록 개발하는 것을 목표로 합니다.

## 구현 방향

CleanTrace는 NeoForge의 클라이언트 이벤트와 필요한 경우 Mixin을 이용해 Minecraft의 기본 스크린샷 동작을 확장합니다.

스크린샷 처리 과정은 대략 다음과 같습니다.

```text
F2 입력
    ↓
스크린샷 요청
    ↓
촬영 정보 저장
    ├─ 좌표
    ├─ Dimension
    ├─ Yaw
    └─ Pitch
    ↓
스크린샷용 프레임 렌더링
    ├─ World
    ├─ HUD
    └─ Chat
         ├─ 채팅 화면 열림 → 렌더링
         └─ 채팅 화면 닫힘 → 렌더링 제외
    ↓
Framebuffer 캡처
    ↓
좌표 기반 파일명 생성
    ↓
PNG 메타데이터 기록
    ↓
스크린샷 저장
```

## 개발 상태

현재 CleanTrace는 초기 개발 단계입니다.

초기 버전 `0.1.0`에서는 다음 세 기능의 구현을 우선 목표로 합니다.

1. 좌표를 포함한 스크린샷 파일명
2. 좌표, 차원, Yaw, Pitch의 PNG 메타데이터 기록
3. 채팅 화면의 상태에 따른 채팅 메시지 자동 제외

이후 필요에 따라 설정 화면이나 추가 메타데이터 항목 등을 확장할 수 있습니다.
